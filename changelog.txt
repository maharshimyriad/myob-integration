*** Stars MYOB AccountRight Connector for WooCommerce — Changelog ***

2025-07-06 - version 1.0.0
* Initial release under Stars branding.
* Plugin activates gracefully without WooCommerce — shows admin notice instead of fatal error.
* Removed legacy third-party branding and internal ticket references.
* Security: removed malicious file that allowed unauthorised server writes.
* OAuth callback updated to stars-myob-cronjob.php.
* All plugin files renamed to stars-* convention.
